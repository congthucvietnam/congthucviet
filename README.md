## ✨ Tính Năng Nổi Bật

- 🧮 **Tương thích 100% MathType OLE 7.0 (DSMT4):** Chèn công thức chuẩn Word OLE, nhấp đúp để sửa, không bao giờ bị méo chữ, lệch dòng (baseline) hay đen hình khi in ấn.
- ⚡ **Gõ LaTeX siêu tốc & Trực quan:** Bảng ký hiệu đầy đủ chuẩn SGK Việt Nam (Hệ phương trình, Tích phân, Ma trận, Hình học không gian, Vec-tơ, Hóa học...).
- 🤖 **Studio Trợ lý AI Tạo Đề Thi GDPT 2018:** 
  - Tự động sinh đề kiểm tra từ chủ đề hoặc file đề cương đính kèm qua ChatGPT / Gemini.
  - Tự động định dạng chuẩn ma trận: Trắc nghiệm 4 lựa chọn, Trắc nghiệm Đúng/Sai, Trả lời ngắn, Tự luận và Bảng đáp án có lời giải chi tiết.
- 🛡️ **Bảo vệ tài liệu giáo án:** Không bao giờ cưỡng chế tắt Word, cơ chế sao lưu và phục hồi an toàn tuyệt đối.
- 🔄 **Cập nhật tự động thông minh:** Nhẹ nhàng kiểm tra phiên bản mới, hỗ trợ 2 kênh Stable và Dev linh hoạt.

## 🛠️ Hướng Dẫn Cài Đặt 1-Click

1. Tải file `Setup_CongThucViet.exe` từ bảng tải về ở trên.
2. Đóng Microsoft Word trước khi cài đặt.
3. Chạy file `Setup_CongThucViet.exe` ➔ Bấm **Cài đặt**.
4. Mở Microsoft Word, Thầy/Cô sẽ thấy tab **Công Thức Việt** xuất hiện trên thanh Ribbon!
